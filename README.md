# Simulador de carga académica PUCV

Simulador interactivo para comparar las horas reconocidas por la calculadora institucional de la PUCV con una estimación del tiempo real de las actividades académicas.

## Abrir el simulador

La página que debes abrir es:

[Abrir el simulador](https://dar10p.github.io/carga-academica-pucv-simulador/)

Los archivos HTML, JavaScript y datos de apoyo del simulador están en este repositorio.
